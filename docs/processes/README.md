# Процессы

Здесь хранятся сквозные описания бизнес- и пользовательских процессов.

Каждый процесс должен содержать:

- цель и границы;
- участников;
- предусловия;
- триггер;
- основной поток;
- альтернативные и ошибочные потоки;
- бизнес-правила;
- статусы и переходы;
- связанные требования;
- связанные решения;
- открытые вопросы и известные конфликты.
